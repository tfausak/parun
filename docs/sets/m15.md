# Magic 2015 census

The Magic 2015 (M15) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-27 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5712: The Chain Veil. Nothing reads a player's loyalty activations this
  turn, and nothing grants a planeswalker one more loyalty activation after
  CR 606.3's one.
- #5713: Hushwing Gryff. No static ability can stop a creature's entering from
  triggering abilities; the trigger funnel consults no continuous effect.
- #5714: Master of Predicaments. No prompt asks a player to guess about a card
  hidden from them, and nothing branches on the guess.
- #5715: Garruk, Apex Predator. `Effect.CreateEmblem` always gives the emblem to
  the resolving controller; its −8 gives one to a target opponent.
- #5716: Ob Nixilis, Unshackled. Searching a library is not a `PlayerAction`,
  so "whenever an opponent searches their library" has no event.
- #5717: Diffusion Sliver. `PermanentBecomesTargeted` has no relation for the
  targeting object's controller and does not bind that object to counter it.
- #5718: Feast on the Fallen, First Response. No quantity reads the life a
  player lost last turn.
- #4603: Kurkesh, Onakke Ancient. Nothing triggers on activating an ability.
- #5719: Yisan, the Wanderer Bard. A cost can put only +1/+1 counters on its
  own permanent, not a verse counter.
