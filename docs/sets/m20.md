# Core Set 2020 census

The Core Set 2020 (M20) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-31 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per line)
and running `parun deck` on it: every unresolved name is reported.

## Expressible today

Every expressible Core Set 2020 card has been added to `data/cards/`.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5851: Scuttlemutt. A colour choice picks exactly a fixed number of colours,
  never "the color or colors of your choice".
- #5854: Veil of Summer. A player's hexproof (`CantBeTargetedBy`) takes no
  quality, so "you gain hexproof from blue and from black" has no carrier.
- #5855: Vengeful Warchief. The life-loss trigger has no "for the first time
  each turn" narrowing.
