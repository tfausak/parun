# Core Set 2020 census

The Core Set 2020 (M20) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-31 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per line)
and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5837: Yarok, the Desecrated. Nothing makes a triggered ability trigger an
  additional time (CR 603.2d).
- #5799: Kethis, the Hidden Hand. A graveyard play permission permits a cast,
  never a land play, and a legendary land is a legendary card.
- #5839: Leyline of Combustion. No trigger watches a player and the permanents
  they control becoming targets as one batch.
- #5838: Atemsis, All-Seeing; Embodiment of Agonies. `DistinctOf` counts card
  types, colors and basic land types, not mana values or mana costs.
- #5844: Flood of Tears. A count over the permanents a bounce returned to
  hand reads the hand cards, not what they were on the battlefield.
- #5842: Chandra's Regulator; Repeated Reverberation. No filter asks whether
  an ability on the stack is a loyalty ability.
- #5848: Pattern Matcher. No filter matches a card's name against any of a
  group of permanents.
- #5846: Heart-Piercer Bow. An Equipment's attack trigger reads "defending
  player" off the Equipment, not the equipped attacker.
