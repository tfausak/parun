# Magic 2011 census

The Magic 2011 (M11) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-25 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Expressible today

Every expressible Magic 2011 card has been added to `data/cards/`.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5176: Necrotic Plague. Its dies trigger's target is chosen by the dead
  creature's controller, who doesn't control the ability, and "their opponents"
  is relative to that chooser; targets are chosen only by the ability's
  controller or a player held in a slot today.
- #5609: Autumn's Veil. Two new pieces: uncounterability filtered by the
  countering spell's colour, and a turn-long targeting ban whose affected set is
  read live rather than fixed at resolution.
- #5610: Phylactery Lich. An entry replacement that chooses another permanent
  and puts a counter on it; entry counters reach only the entering object.
- #5540: Obstinate Baloth. The discard's cause is already recorded, but a
  replacement's pattern has no field for who controls it.
- #5611: Chandra's Spitfire. One parameter: a damage kind on the existing
  player-is-dealt-damage trigger.
