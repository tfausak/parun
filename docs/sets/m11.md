# Magic 2011 census

The Magic 2011 (M11) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-25 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Expressible today

Every expressible Magic 2011 card has been added to `data/cards/`.

## Needs a capability

Nothing. Every Magic 2011 card is in the pool.
