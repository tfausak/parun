# Magic 2012 census

The Magic 2012 (M12) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-26 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5666: Vengeful Pharaoh. One batch of combat damage reaching you and your
  planeswalkers; the player trigger never sees a planeswalker, and the
  permanent trigger fires once per damage event.
- #5667: Chandra, the Firebrand. A delayed trigger that fires on the next
  cast and ends with the turn; an armed duration keeps firing today.
- #5668: Jace's Archivist. A per-player count of the cards each player
  discarded this way, for the greatest of them.
- #5669: Flameblast Dragon. A resolution-time payment whose X the payer
  chooses; an X in a payment reads only the X announced while casting.
- #5670: Hunter's Insight. One parameter: planeswalkers among the recipients
  of the filtered combat-damage trigger.
- #5671: Grand Abolisher. One parameter: a source filter on the player-side
  activation ban, which narrows only by keyword.
- #5672: Adaptive Automaton. One parameter: a mode and a creature family on
  the chosen-subtype modification, which only sets a basic land type.
- #5673: Stave Off. A colour chosen as a spell resolves is read live off the
  spell; the resolution lock-in skips a granted protection.
