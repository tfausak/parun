# Magic 2012 census

The Magic 2012 (M12) cards not yet in the pool, and which wait on a capability.
Derived 2026-10-26 from MTGJSON's set list against `data/cards/`. The set list
is `data/decks/sets/m12.txt`, which the suite reads, so every card of the set
stays in the pool.

## Needs a capability

Nothing. Every Magic 2012 card is in the pool.
