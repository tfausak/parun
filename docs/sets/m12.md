# Magic 2012 census

The Magic 2012 (M12) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-26 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Nothing. Every Magic 2012 card is in the pool.
