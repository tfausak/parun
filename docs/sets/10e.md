# Tenth Edition census

The Tenth Edition (10E) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-24 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Expressible today

None: every Tenth Edition card the DSL expresses is in the pool. No missing
Tenth Edition card's whole text is keywords, so `script/ingest` adds none of
them.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5575: No Rest for the Wicked. Nothing reads where a graveyard card came from
  this turn; the battlefield-only "entered this turn" filter needs a zone.
- #5190: Incinerate. A damage instruction records nothing about what it actually
  damaged, so "a creature dealt damage this way" has nothing to name.
- #5576: Soulblast. A sacrifice cost takes a fixed or announced number of
  permanents, never all of them; the fix is an arm of the count.
- #5577: Phage the Untouchable. The damage-to-a-creature trigger fires on any
  damage; it needs the damage kind as a parameter, and must bind what it damaged.
- #5578: Karplusan Strider. The printed targeting prohibition has no filter on
  the spell doing the targeting.
- #5579: Knight of Dusk. The filter for a creature the source blocks has no
  converse for a creature blocking the source.
- #5588: Nomad Mythmaker. An Aura moved onto the battlefield is offered every
  host its enchant ability allows; nothing narrows that to "a creature you
  control".
- #5519: Vampire Bats. An activation can be limited to once each turn, not to a
  number of times.
