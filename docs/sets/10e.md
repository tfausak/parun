# Tenth Edition census

The Tenth Edition (10E) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-24 from MTGJSON's set list against `data/cards/`.
The set list is `data/decks/sets/10e.txt`, which the suite reads, so every card
of the set stays in the pool.

## Expressible today

Every expressible Tenth Edition card has been added to `data/cards/`.

Nothing. Every Tenth Edition card is in the pool.
