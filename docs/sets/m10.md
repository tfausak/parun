# Magic 2010 census

The Magic 2010 (M10) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-25 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Expressible today

Every expressible Magic 2010 card has been added to `data/cards/`.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5594: Master of the Wild Hunt. The damage back is divided as the effect
  resolves, by the target's controller, among objects that were never targets;
  every existing division is announced while casting, among targets.
- #5595: Fireball. Two parameters at once: a per-target cost change that skips
  the first target, and a quantity divided by the number of targets.
- #5596: Mirror of Fate. Resolution-time card choices reach a graveyard or a
  hand but not exile; the fit is a zone on the existing choice.
- #5597: Capricious Efreet. Random picks draw from one zone, never from the
  objects an ability targets.
- #4871: Soul Bleed. A step trigger fires on your turn, an opponent's or every
  turn, never on a named player's.
- #5598: Vampire Nocturnus. A count can read a graveyard's top card but not a
  library's; the fit is a zone on that scope.
- #5599: Dragon Whelp. Activations this turn are already counted for a gate,
  but no quantity reads the count.
