# Starter 2000 census

The Starter 2000 (S00) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-22 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `pawl deck` on it: every unresolved name is reported.

## Expressible today

Every Starter 2000 card was already in the pool when this census was taken.

## Needs a capability

Nothing: every Starter 2000 card is in the pool.

## Decks

MTGJSON lists five S00 decks, all in `data/decks/` as `starter-2000-*.txt`:
both starter decks (Player A's and Player B's, as `starter-1` and
`starter-2`), both advanced packs, and the sampler pack. The advanced packs
carry nine Sixth Edition cards, added with this census: Flame Spirit, Orcish
Oriflamme, Rod of Ruin, Shock and Soul Net, and Samite Healer, Flight, Hero's
Resolve and Inspiration.
