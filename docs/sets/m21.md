# Core Set 2021 census

The Core Set 2021 (M21) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-01 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per line)
and running `parun deck` on it: every unresolved name is reported.

## Expressible today

Every expressible Core Set 2021 card has been added to `data/cards/`.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5874: Teferi, Timeless Voyager. Nothing holds a phased-out permanent back from
  phasing in (CR 702.26a).
- #5875: Necromentia. A search doesn't record which zone each found card came
  from, so it can't count those from the hand.
- #5876: Enthralling Hold. A target filter is re-read on resolution, where this
  restriction applies only as the spell is cast (CR 601.2c).
- #5877: Furious Rise. No duration ends when its source exiles another card.
- #4933: Demonic Embrace. A card's permission to cast itself from a graveyard
  carries no cost of its own (CR 113.6f).
- #5878: Chandra's Incinerator; Chandra's Pyreling. A damage trigger takes a
  source or a damage kind, not both, and the turn's damage total takes no kind.
- #5879: Hooded Blightfang. No damage trigger names a planeswalker as what was
  dealt damage.
