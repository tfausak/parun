# Core Set 2021 census

The Core Set 2021 (M21) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-01 from MTGJSON's set list against `data/cards/`.
The set list is `data/decks/sets/m21.txt`, which the suite reads, so every card
of the set stays in the pool.

## Expressible today

Every expressible Core Set 2021 card has been added to `data/cards/`.

## Needs a capability

Nothing. Every Core Set 2021 card is in the pool.

  - #5900: the before-departure board was picked by whether the bearer left,
    a later cost part erased an earlier one's board, and `LeftTheGame` filed
    none.
  - #5906: a stickered card's escape and flashback were priced with the
    row's cost; blitz and disturb were forced through the paying row.
  - #5907: the damage history roster ignored range of influence (CR 801.11).
- Cost (`script/session-tokens.sh` over the set's transcripts, the last before
  this write-up; no separate orchestrator): cache reads 0.20B; cache writes
