# Portal Three Kingdoms census

The Portal Three Kingdoms (PTK) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-22 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Expressible today

Every expressible Portal Three Kingdoms card has been added to `data/cards/`.

## Needs a capability

Nothing: every Portal Three Kingdoms card is in the pool.

## Decks

MTGJSON lists five PTK decks, all in `data/decks/` as
`portal-three-kingdoms-*.txt`: both preconstructed starter decks, and the Shu
Kingdom, Wei Kingdom and Wu Kingdom theme decks.
