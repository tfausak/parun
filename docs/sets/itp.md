# Introductory Two-Player Set census

The Introductory Two-Player Set (ITP) cards not yet in the pool, and which wait
on a capability. Derived 2026-11-06 from MTGJSON's set list against
`data/cards/`. The set list is `data/decks/sets/itp/all.txt`, which the suite
reads, so every card of the set stays in the pool.

## Expressible today

Every Introductory Two-Player Set card was already in the pool when this
census was taken.

## Needs a capability

Nothing: every Introductory Two-Player Set card is in the pool.

## Decks

MTGJSON lists four ITP decks, all in `data/decks/sets/itp/`: Kazz's first and
second decks and Zakk's first and second decks, 30 cards each and every card
from the set. `DecksSpec`'s starter bot game plays Kazz's first deck against
Zakk's first deck.
