# Core Set 2019 census

capability. Derived 2026-10-30 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5813: Palladia-Mors, the Ruiner. `DealtDamageThisTurn` reads the turn's log
  only; "hasn't dealt damage yet" needs a memory that outlives the turn.
- #5814: Suncleanser. A counter restriction exists only as a face's static
  ability; none can be made by a resolution over a target "for as long as".
- #5812: Detection Tower. The targeting gate has no exemption letting a player
  target past hexproof.
- #5821: Liliana, the Necromancer. `ChosenCardInGraveyard` counts exactly, so
  the −7's "up to two creature cards from graveyards" can't take fewer.
- #5815: Alpine Moon. `LoseEveryCreatureSubtype` has no land counterpart.
- #5817: Banefire. A can't-be-countered condition is judged with no X bound,
  so "if X is 5 or more" never holds.
- #5820: Inferno Hellion. Nothing asks whether a creature blocked this turn;
  `AttackedThisTurn` has no blocking counterpart.
