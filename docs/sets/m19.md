# Core Set 2019 census

The Core Set 2019 (M19) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-30 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Expressible today

Every expressible Core Set 2019 card has been added to `data/cards/`.

## Needs a capability

Nothing. Every Core Set 2019 card is in the pool.

Finished 2026-10-31.

- Filed along the way: #5824 (search trims an over-long answer), #5826
  (per-player target copy with no candidates, Vaevictis Asmadi), #5828
  (plus-loyalty cost on a counter-forbidden planeswalker), #5830 (mandatory
  blight onto a creature that can't take the counters), #5832 (up-to
  graveyard choice under each-in-scope).
- Audits: 6 of 7 capability PRs (#5835 skipped: data plus a comment), plus
  hand batches #5823 and #5825; findings went to a fresh fixer. 2 found
  rules defects, both predating their PR:

    counters (fixed in the PR).

    controlled no permanents (filed as #5826).
- Cost (`script/session-tokens.sh` over the set's transcripts): cache

  The costliest units: #5825 (72M, including a killed audit), #5819 (39M),

  - #5830: needs-planning, whether a mandatory blight may pick a creature

  - Wire-format changes: #5827 `Filter.DealtDamageToThisTurn` ->
