# Magic 2014 census

The Magic 2014 (M14) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-27 from MTGJSON's set list against `data/cards/`.
The set list is `data/decks/sets/m14.txt`, which the suite reads, so every card
of the set stays in the pool.

## Needs a capability

Nothing. Every Magic 2014 card is in the pool.

- Census trend: the first dry run translated 49 of the 122 missing; 2

- Capability issues, hardest first: #5701 Savage Summoning (#5707, after
  its blocker #3798 Boreal Outrider, #5704), #4277 Ratchet Bomb (#5710, with
  The Filigree Sylex), #5700 Haunted Plate Mail (#5708). Found by #5709:
  #4277.
- Filed along the way: #5703 (Runadi's "mana value minus 4" needs a
  reading), #5706 (a stored player effect can't read a slot its own
  resolution bound; Vexing Shusher).
- Audits: 4 of 4 capability PRs; 0 found rules defects. Their low findings
  (a duplicated slot rename, false pool claims in `Projection` comments,
  unobserved card data and riders) were folded before merge.
- Subagent tokens: census 356k; hand 426k, 377k; capability 213k (#5704),
  342k (#5707), 221k (#5708), 249k (#5710); audits 138k, 149k, 139k, 166k,
  in the same order. Total 2.78M, 22.8k per card. Wall clock ~4.5h, two
  lanes.
- Owner review:
  - #5703: which reading of Runadi's "where X is its mana value minus 4"
    (an {X} spell, a creature entering as a copy).
  - #5704: only floating `EntryR` rows are re-keyed onto the permanent
    (`Event.reenter`); Boreal Outrider's row is `Indefinite`.
  - #5707: `Duration.UntilUsed` / `Expiry.WhenUsed` take an optional slot
    (wire change; the bare tag still decodes); `ActivePlayerEffect.slots`.
  - #5708: `Modification.RemoveSubtype` as its own constructor rather than
    a direction on `AddSubtype`.
  - #5710: `Effect.BindAmount` for a computed amount rather than widening
    `ChooseNumber`.
