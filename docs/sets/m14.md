# Magic 2014 census

The Magic 2014 (M14) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-27 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5701: Savage Summoning. "The next creature spell you cast this turn" binds
  nothing, so neither "that spell can't be countered" nor "that creature enters
  with an additional +1/+1 counter" can name the spell; a one-shot player effect
  is spent by the cast it matches.
- #5700: Haunted Plate Mail. Becoming an artifact creature "that's no longer an
  Equipment" needs one artifact subtype dropped; layer 4 can add one but not
  remove it.
