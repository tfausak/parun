# Magic 2013 census

The Magic 2013 (M13) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-27 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5306: Disciple of Bolas. A later instruction reading the creature an
  earlier one sacrificed; only a target or a cost's sacrifice keeps its last
  known information (CR 608.2h).
