# Magic 2013 census

The Magic 2013 (M13) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-27 from MTGJSON's set list against `data/cards/`.
Re-derive the missing list by writing the set list as a deck (`1 Name` per
line) and running `parun deck` on it: every unresolved name is reported.

## Needs a capability

Each card is tracked by its issue and is added when that issue lands. Hardest
first.

- #5390: Odric, Master Tactician. Its controller declares another player's
  blocks; the declaration is always the defending player's, and the CR 509.1
  legality checks would have to stay theirs while someone else chooses.
- #5684: Gem of Becoming. One search finding three cards that each match their
  own description; a search has one description for every card it finds, and
  three searches in a row are not one (CR 701.23h).
- #5306: Disciple of Bolas. A later instruction reading the creature an
  earlier one sacrificed; only a target or a cost's sacrifice keeps its last
  known information (CR 608.2h).
- #5683: Serra Avenger. A cast barred during its controller's first three
  turns; the game counts its own turns, not each player's.
