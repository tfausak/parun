# Magic 2013 census

The Magic 2013 (M13) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-27 from MTGJSON's set list against `data/cards/`.
The set list is `data/decks/sets/m13.txt`, which the suite reads, so every card
of the set stays in the pool.

## Needs a capability

Nothing. Every Magic 2013 card is in the pool.

Finished 2026-10-27.

- Census trend: the first dry run translated 46 of the 111 missing; 3

  #5684 Gem of Becoming (#5689), #5683 Serra Avenger (#5691). Found by

- Filed along the way: #5686 (a cast bounded to combat before blockers),
  #5688 (a player who left during beginning of combat can still be
  attacked), #5693 (position lints miss a split card's right half; closed by
  #5694). Follow-up PRs: #5696 (MTGJSON's Oracle restamps; Magmaquake's
  reading proven), #5697 (the set lists).
- Audits: 4 of 4 capability PRs; 3 found rules defects.
  - #5687: a chooser who had left the game was still handed the
    declaration; the toll was offered when unpayable; refusing could empty a
    declaration that must attack.
  - #5691: first turns were counted from the seating head, not recounted
    when the starting player changes.
  - #5694: a sacrifice redirected to a hidden zone failed Shadowgrange
    Archfiend's gate (Soulblast too).
- Subagent tokens: census 346k; hand 510k, 415k; capability 375k (#5687),
