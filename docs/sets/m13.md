# Magic 2013 census

The Magic 2013 (M13) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-27 from MTGJSON's set list against `data/cards/`.
The set list is `data/decks/sets/m13.txt`, which the suite reads, so every card
of the set stays in the pool.

## Needs a capability

Nothing. Every Magic 2013 card is in the pool.
