# Starter 1999 census

The Starter 1999 (S99) cards not yet in the pool, and which wait on a
capability. Derived 2026-10-22 from MTGJSON's set list against `data/cards/`.
The set list is `data/decks/sets/s99.txt`, which the suite reads, so every card
of the set stays in the pool.

## Expressible today

Every expressible Starter 1999 card has been added to `data/cards/`.

## Needs a capability

Nothing: every Starter 1999 card is in the pool.

## Decks

MTGJSON lists nine S99 decks, all in `data/decks/` as `starter-1999-*.txt`:
both preconstructed starter decks, both demo decks, and the Blinding Fury,
Deadly Instinct, Goblin Assault, Impaler and Time Curse theme decks.
